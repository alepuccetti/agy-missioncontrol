# Security Policy

## Supported Versions

Security fixes are provided for the latest release on the `main` branch.

| Version | Supported |
| ------- | --------- |
| 0.2.x   | Yes       |
| < 0.2.0 | No        |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report vulnerabilities privately using GitHub's Private Vulnerability Reporting:

- [Report a security vulnerability](https://github.com/alepuccetti/agy-missioncontrol/security/advisories/new)

Please include as much detail as possible:

- Description of the vulnerability and potential impact
- Steps to reproduce or a proof-of-concept
- Affected component(s) (CLI, quota governor, web dashboard, Antigravity plugin/hooks, or release artifacts)
- Any suggested remediation, if known

You can expect an initial acknowledgment within 72 hours and regular status updates as the issue is investigated and remediated.
